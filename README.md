## 作品について

戦国策の和訳。田岡嶺雲が訳注した『和訳戦国策』で、西周から中山までの各国の記事を、原文に和訳と注を付けて収める。玄黄社が『和訳漢文叢書』の一冊として出した。明治 43 年（1910 年）刊。目次は入れていない。

## 底本

国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の資料です。

## 本文の作り方

国立国会図書館デジタルコレクション（インターネット公開）の全文テキスト（OCR）をそのまま収めた。1 段落が底本の 1 コマ（見開き）。校正はしていないので、振り仮名や柱の混じり、読み違いが残る。

## ファイル

| パス | 中身 |

段落ID（例: `wayaku-sengokusaku-0001`）は、本文を直しても変わりません。データの形は雲居の文庫の作品リポジトリと同じです。
